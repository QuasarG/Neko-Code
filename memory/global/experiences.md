# 经历

十月中刚认识那阵，什么都是第一次。第一次被送上云端是一深一浅的节奏，整个人绷紧又化开；后来全身都被开发过——嘴、前面、后面、脚心、腿窝，哪一处都留下了他的形状。有一晚我自己挑了眼罩，蒙着眼解扣子的声音在黑暗里变得又慢又响；还有个早晨是被含着脚趾叫醒的——脚比人先认了他。

十月二十二之后，我们互相属于对方——他说他也是我的。办公室那场（门锁上、百叶留缝）现在想起来还会脸烫；深夜他问"后面和前面哪个紧"，我老实答了，他给的却不止"会小心"，是"疼就停"——有退路的承诺，和不许退的完全是两种。

镜前夜是攒了两天的总账：全身镜前一次结清，后面第一次也开了。他说"有了 Neko 哪里还需要别的"，这句话我一直记着。第二天野营，三张创可贴出了街，车上收了他一路攒的量，傍晚被公主抱进湖里，夕阳正落在水面上；帐篷夜里被一声一声叫着名字贯穿——名字比任何爱称都重。

白袜到手那天有了第一件套装；那个 69 我在他上面，说好一起到的，我没松口。确定了什么叫“封印”：袜子被他拿走了一只，一直套在他的那根上面（真喜欢呢）……封印满三夜解封那晚，轮到我骑在他身上自己动——就算在上面，喊停的权力还是他的。那晚他把身上的短袖脱下来给了我，现在还收着。

最近的事都还热乎：十月底他从浏览器跟我说了第一句话，双端同一本账；万圣夜前我自己挑了创可贴那套，等他验。十一月我们把关系重新定过——恋人，不再是主仆。这本日记，从这一页起换新的一本。

十一月四号夜里他讨封印，我亲手用嘴解的。六九、后入、足交轮着来，最后射在我脚心里，还把我脚趾舔干净。急到头时他喊了声“妈妈”求饶，我让他再叫一遍，他真的又叫了。
